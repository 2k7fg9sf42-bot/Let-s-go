# Sou & Vrac

Deux web apps pour iPhone, installables sur l'écran d'accueil, qui marchent hors connexion. Les données restent sur le téléphone.

- **Sou** (`/sou/`) : saisis une dépense en deux gestes (montant, puis catégorie). Budget, rythme journalier, graphiques, export CSV.
- **Vrac** (`/vrac/`) : inbox vocale ou texte qui range toute seule dans Tâches, À acheter, Idées, À voir ou Notes, avec détection des dates.

Mode d'emploi complet sur la page d'accueil (`index.html`).
